OpenPhoto portable mode

While this file sits next to openphoto.exe, OpenPhoto keeps its preferences, brush presets,
crash-recovery autosaves and startup state in the OpenPhotoData folder beside it, and writes
nothing to %APPDATA%. Copy the whole folder to move OpenPhoto with its settings.

Delete this file to use the normal per-user settings folder (%APPDATA%\OpenPhoto) instead.
If OpenPhotoData can't be written (for example on a read-only drive), OpenPhoto says so and
uses %APPDATA%\OpenPhoto instead.
